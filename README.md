# IPL Performance Intelligence Dashboard

An end-to-end IPL analytics project using **PostgreSQL, Power BI and Excel** to analyze player, team and match performance across IPL seasons.

## Project Overview

This project analyzes **260,920 IPL deliveries and 1,095 matches** from **17 IPL seasons (2008–2024)**.

The analysis covers:
- Batting performance
- Bowling performance
- Team wins and performance
- Player performance
- Toss impact
- Match result patterns
- Season-wise trends
- Powerplay and death-over analysis

## Tools & Technologies

- **PostgreSQL** — Data storage, SQL analysis and performance views
- **Power BI** — Interactive dashboard and visual analytics
- **Excel** — Data preparation and exploration

## Key Insights

- Identified top IPL run scorers and leading wicket takers.
- Compared players based on fours and sixes.
- Analyzed team win trends across seasons.
- Examined toss decisions and match outcomes.
- Analyzed match-result distributions and seasonal trends.
